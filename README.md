# 讀懂物理｜講義 × 課本 × 考試書寫

物理系課程的讀書網站：力學、熱學、近代物理、光學、應用數學，依老師講義的頁碼順序講解，每一題附精簡步驟解題和「考試書寫版」。

- 網站：https://rich88970.github.io/physics-study-site/
- 專案規則（給 AI 的開發說明）：[AGENTS.md](AGENTS.md)

## 內容

| 科目 | 章節 |
| --- | --- |
| 力學（Thornton & Marion） | Lecture 1 向量與向量微積分、Lecture 2 單一質點牛頓力學、公式表 |
| 熱學（Schroeder） | 第 1、2 章、考古題（第 1、2 章範圍） |
| 近代物理（Beiser） | 第 1 章相對論、第 2 章波的粒子性 |
| 光學 | 講義第八～十章、考古題同類題詳解 |
| 應用數學 | 第 1～6 章（一階 ODE 到 Bessel）、考古題與作業 |

功能：每節一頁、考試模式（收起解說只留題目與思路）、考試書寫版側欄、逐步圖解、深淺色、手機版。

## 本機開啟

直接雙擊 `index.html`，或 `python -m http.server` 後開 `http://localhost:8000`。改內容後依 AGENTS.md 第 6 節重新打包與檢查。
